CLI

The same crypto core, from the terminal.

Run these from the project directory. The sample password is built in.

Hide a message 
python oversec_stego.py encrypt --password "your password" --message "meet me at midnight" --output hidden.txt
Reveal a message 
python oversec_stego.py decrypt --password "your password" --text-file hidden.txt
Decrypt the sample 
python oversec_stego.py decrypt --sample

How it works

The format, the keys, and the one repair.

A compatible reimplementation of Oversec’s zero-width format. It preserves the quirks that matter for real messages.

Password key
bcrypt cost 8 with the fixed SIMPLESYM salt. The key ID is bcrypt of SHA-384(raw)[32:48] at cost 6.
Session key
bcrypt of the key ID and the per-message salt at cost 5. The first 8 bytes are the keyhash.
Message key
bcrypt of SHA-384(raw)[0:32] and the salt at cost 4. Both halves repeat the first 16 bytes, matching Oversec’s bug.
Cipher
ChaCha20 with an 8-byte IV, then Poly1305 over the ciphertext with zero padding and an 8-byte little-endian length.
Encoding
OSC magic, a delimited protobuf envelope, and the zero-width mapping 0x00–0x0F to U+FE00–U+FE0F; the rest to U+E0100–U+E01EF.
Repair
If one byte is missing, the decoder tries every insertion and keeps the one the Poly1305 tag accepts.

Not affiliated with Oversec. Use it on messages you have permission to read.
