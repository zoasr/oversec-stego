# Self-hosted fonts

These are the Latin subsets of three SIL Open Font License 1.1 families,
downloaded from Google Fonts for local use by the Zero Width workbench:

- **Familjen Grotesk** by Eric Olson, weights 500 and 600.
  <https://fonts.google.com/specimen/Familjen+Grotesk>
- **IBM Plex Sans** by IBM, weights 400 and 500.
  <https://fonts.google.com/specimen/IBM+Plex+Sans>
- **JetBrains Mono** by JetBrains, weights 400 and 500.
  <https://fonts.google.com/specimen/JetBrains+Mono>

The SIL Open Font License permits redistribution and embedding. The license
text is available at <https://openfontlicense.org/>. The font files retain
their original license metadata.
